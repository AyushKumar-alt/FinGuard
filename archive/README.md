# FinGuard: Project Archive & Historical Artifacts

## Overview

This directory preserves historical logs, obsolete experimental scratch notes, and superseded benchmark runs for reproducibility and audit integrity.

---

## Contents & Preservation Policy
- All original historical data splits, metric JSONs, and model weights remain permanently preserved in their designated `data/`, `outputs/`, and `models/` locations.
- No historical records or evaluation matrices have been deleted or overwritten.
